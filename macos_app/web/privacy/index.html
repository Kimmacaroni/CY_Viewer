CY뷰어 개인정보 안내

적용일: 2026년 9월 27일

기본 사용

로그인하지 않아도 PDF를 열고 읽을 수 있습니다. 웹앱은 최근 PDF 5개의 사본을 해당 브라우저에 저장합니다. 기기의 저장 공간 정리나 브라우저 데이터 삭제로 사본이 사라질 수 있으므로 원본을 별도로 보관하세요.

선택한 경우에만 Google Drive 연결

Google Drive 연결을 선택하고 Google 권한 화면에서 동의하면, 이후 여는 PDF 원본과 파일명, 책갈피 및 읽던 페이지를 사용자의 개인 Google Drive에 저장합니다. CY뷰어는 앱이 만들거나 사용자에게 허용받은 파일에 접근하는 drive.file 권한을 요청합니다. Drive의 모든 파일에 접근하는 권한은 요청하지 않습니다.

파일은 Google Drive API를 통해 사용자의 Drive로 직접 전송하며 CY뷰어 운영자의 파일 저장 서버를 거치지 않습니다. 계정 이메일은 현재 연결 계정을 표시하는 데 사용합니다. 인증 토큰은 현재 앱 실행의 메모리에 유지하며 앱 종료 후 다시 연결해야 합니다.

보관과 삭제

최근 목록에는 최대 5개를 표시합니다. 목록에서 밀려난 PDF도 Drive에 남고 개인 계정의 저장 용량을 사용합니다. Drive에서 직접 파일을 삭제할 수 있습니다. 연결 해제는 저장된 파일을 삭제하지 않습니다. Google 계정의 타사 앱 연결 관리에서 CY뷰어 권한을 철회할 수 있습니다.

사용 목적

Google에서 받은 데이터는 사용자가 요청한 PDF 동기화와 이어 읽기에만 사용합니다. 광고, 판매, AI 모델 학습 목적으로 사용하지 않습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

문의

CY뷰어 GitHub 문의 또는 Google 로그인 동의 화면에 표시된 지원 이메일로 문의할 수 있습니다. 공개 문의에 PDF 원본이나 인증 정보를 첨부하지 마세요.

CY Viewer privacy notice

You can read local PDFs without signing in. The web app stores copies of your 5 most recent PDFs in your browser.

If you choose to connect Google Drive and grant access, PDFs opened afterwards, file names, bookmarks and reading position are sent directly to your own Drive. Only the drive.file scope is requested. Files are not stored on a CY Viewer operator server. Your email identifies the connected account. Access tokens remain in memory during this app session; reconnect after restarting.

Only the 5 most recent files are listed. Older files remain in Drive and use your storage quota. You may delete files in Drive and revoke access in your Google account. Disconnecting does not delete files. Google data is used only for document sync and reading, never for ads, sale or AI training. Use and transfer of Google API data complies with the Google API Services User Data Policy, including Limited Use requirements.
