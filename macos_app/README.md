# CY뷰어 for macOS

CY뷰어 메인 저장소에서 관리하는 macOS용 앱입니다.

## 대상 환경

- macOS 12 Monterey 이상
- Apple Silicon 및 Intel Mac

## 사용자 기능

- PDF 열기와 문서 탐색
- 페이지 이동 및 확대·축소
- 문서 검색
- 텍스트 선택과 표시
- 페이지 책갈피
- Finder에서 PDF 끌어놓기
- macOS 시스템 인쇄 창
- CY뷰어 전용 앱 아이콘

완성된 macOS 설치 파일은 공개 [CY뷰어 다운로드 저장소](https://github.com/Kimmacaroni/CY_Viewer_Download/releases)에만 게시합니다.
