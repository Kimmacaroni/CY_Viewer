# 아이폰 홈 화면 웹앱 입력 조사

2026-10-15 사용자가 홈 화면 바로가기로 실행한 웹앱의 터치 먹통을 신고했고, 기기는 아이폰이라고 확인했다. iOS 버전과 발생 단계는 아직 확인되지 않았다.

조사 중 별도의 캐시 결함을 확인했다. HTML은 1.16.3 시작 스크립트를 요청하지만 bootstrap은 앱 본체를 계속 `main.dart.js?release=pdfcraft-all-1.14.0-21`로 요청했다. 시작 스크립트 URL의 배포 식별자를 본체 URL에도 전달하도록 수정했다. 다음 배포에서도 HTML의 식별자만 바꾸면 두 요청이 함께 바뀐다. 이 결함이 사용자 터치 장애의 직접 원인이라고 확정하지 않는다.

배포 식별자는 `iphone-pwa-20261015-1`이다. Mac·Windows 프로그램과 PDF 편집 엔진의 버전은 바꾸지 않았다. 앱 데이터·최근 PDF 사본을 지우거나 새로고침을 강제하지 않는다.

검증:
- Node 회귀 검사: HTML 배포 식별자 전달, 다음 배포의 다른 본체 URL, 쿼리 없는 실행.
- 브라우저 터치 검사: 390×844 모바일 환경에서 실제 터치로 파일 선택기 열기, PDF 도구 열기, 탭 전환, 닫기와 재열기. Chrome과 WebKit, 일반 실행 및 `navigator.standalone` 플래그 실행을 구분한다.
- 브라우저 플래그 모사는 실제 아이폰 홈 화면 컨테이너 검증이 아니다. 사용자 기기의 장애 재현과 해소 여부는 별도로 확인해야 한다.
