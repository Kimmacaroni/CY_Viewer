# PdfCraft 문서 마무리 확대

웹·Mac 1.15.0+22, Windows 1.12.0, 공통 엔진 0.4.0의 변경이다. 기존 페이지 편집 기능에서 서로 다른 문서 작업으로 범위를 확대한다.

## 새로 사용할 수 있는 기능

- 텍스트 워터마크: 출력 전체에 25% 불투명도·45도 대각선 표시. 기존 PdfCraft 워터마크를 교체한다.
- 머리말·꼬리말: 각 페이지 중앙에 지정 문구를 넣는다.
- 페이지 번호: 아래 중앙에 1/n 형식으로 표시한다. 병합·재정렬을 마친 결과 기준이며 ZIP 분할 전 전체 쪽 번호다.
- 여백 자르기·해제: 회전 전 원본 용지의 왼쪽·위·오른쪽·아래 가장자리 기준 mm. 숨기기이며 내용 삭제가 아니다.
- 페이지 배경색: 연한 노랑·파랑. 이미지가 페이지 전체를 덮으면 그 뒤의 배경색이 보이지 않을 수 있다.
- 표시 제거: CY뷰어·PdfCraft가 식별 표시와 함께 넣은 워터마크·머리말·꼬리말·배경만 제거한다. 일반 PDF에 그려진 모든 표시를 지우는 기능은 아니다. 제거 후 새 설정을 적용한다.
- 용량 최적화: PdfCraft optimize 기본 설정. 큰 이미지를 150ppi로 줄이고 JPEG 품질 60으로 저장한다. 쓰지 않는 일부 자료와 스트림도 정리한다. 이미지 화질이 달라지며 용량 감소를 보장하지 않는다.

웹·Mac은 PDF 도구 → 문서 마무리에서 설정한다. Windows는 PDF 도구 작업 선택 목록에서 해당 작업을 고르고 새 파일로 저장한다. Windows의 페이지 변경 기록은 새 작업에도 함께 적용된다. Windows는 마무리 작업을 한 번에 하나씩 저장하며 여러 마무리를 쌓으려면 저장한 결과를 다시 연다. 웹·Mac은 한 번에 여러 설정을 적용할 수 있다.

## 구현·제한

고정 upstream d9607ec3의 pdfcraft-edit·pdfcraft-optimize를 추가 연결했다. 자체 유사 기능을 PdfCraft 기능이라고 표시하지 않는다. 네이티브와 WASM 모두 동일한 finish_document 코드가 실행된다. 기존 파일·시간·원본 보호, 소유자 권한·서명 거부 정책을 유지한다.

upstream 페이지 문구는 표준 Helvetica/WinAnsi를 쓰므로 한글을 지원하지 않는다. UI에 제한을 명시하고 영문·숫자·ASCII 기호로 제한한다. 미지원 문구를 물음표로 조용히 저장하지 않는다. 사용자 입력의 특수 토큰은 거부하고 쪽 번호 토큰만 앱에서 생성한다. 한글 문서 내용·메타데이터·책갈피의 기존 지원과는 별개다.

페이지 번호·머리말·꼬리말은 기존 PdfCraft 머리말 그룹을 교체한다. 좁은 용지나 너무 긴 문구는 upstream에서 거부될 수 있다. CropBox 자르기는 민감정보 삭제 도구가 아니다.

README 상단 PdfCraft 사용·ArtCraft Team·기여자·MIT 고지, 설치본과 웹의 실제 의존성 고지를 유지한다. 새 edit/optimize 의존성의 고지도 빌드에서 생성한다.

## 검증

독립 PyMuPDF 검사에 실제 문구·각 쪽 번호, CropBox 크기, 자르기/표시 해제 후 원본 픽셀 일치, 링크·폼 보존, 한글 문구·잘못된 여백 거부, 1200px 이미지 실제 축소·용량 감소 검사를 추가했다. 브라우저 Chrome·WebKit 작업자 검사, Flutter 저장 요청, 실제 웹 다운로드와 Windows GUI 저장, Mac 샌드박스 PDFKit 검사를 확대했다. 로컬 독립 엔진 11개, Windows 단위 20개 및 GUI 마무리 작업 저장, Flutter 분석·6개 도구 UI 검사·전체 59개(환경 조건 5개 제외), Chrome·WebKit 실제 WASM 마무리·거부·복구 검사가 통과했다. 이후 실제 웹 UI와 OS별 출시 검증을 진행한다.

기존 publish-desktop-versions.yml이 버전 변경을 감지해 고정 태그를 만들고 OS별 검증·릴리스 빌드를 시작한다. 이번 작업에서 추가했던 main 직접 게시 경로는 제거해 기존 태그 게시 흐름으로 통일했다. 공개된 태그는 이동하지 않는다.

대형 용지의 페이지별 UserUnit 배율을 반영해 mm 자르기를 변환한다. 서로 다른 배율·회전 페이지의 실제 크기를 독립 엔진으로 검사한다. 기존 브라우저 캐시도 새 호스트·작업자·WASM 0.4.0 주소로 함께 갱신한다.
