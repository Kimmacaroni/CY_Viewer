목적과 범위
사용자는 Git과 파일에 남은 모든 작업 내용을 이후 작업의 맥락으로 활용하도록 요청했다.
이 기록은 저장소 이력, 프로젝트 지침, README, 설계·문제 수정·배포 문서,
초기 대화 기록 DOCX와 주요 코드 구조를 종합한 인수 자료다.
모든 소스 행을 정밀 검토했다거나 모델을 영구 재학습했다는 뜻은 아니다.
추적 파일 전체의 크기·해시 목록은 PROJECT_FILE_INDEX.json,
로컬에서 확보한 모든 브랜치의 커밋 및 변경 파일은 PROJECT_GIT_HISTORY.txt에 보존한다.
새 작업에서는 현재 Git 상태와 실제 관련 소스를 다시 확인한다.

제품과 소스 구조
- 메인 저장소: Kimmacaroni/CY_Viewer. 소스, 설치 파일, 공개 웹앱을 통합 관리한다.
- Windows 현재 앱: native_windows/cy_viewer.py. Python/Tkinter, PyMuPDF,
  Pillow, pywin32, tkinterdnd2. Tesseract 한국어/영어 전체 문서 OCR.
- Apple 앱: macos_app/lib/main.dart → app.dart 문서함 → advanced_reader.dart.
  Flutter/pdfrx와 Swift 네이티브 연동. Vision OCR, 시스템 인쇄,
  Finder 열기, sandbox security-scoped bookmark와 메뉴 단축키를 포함한다.
- 웹: macos_app/lib/web_main.dart. PDFium 초기화, 직접 HTML 파일 입력,
  IndexedDB 최근 원본, 인쇄 전용 DOM, PDF 저장·공유를 사용한다.
- personal_pdf_viewer는 초기 Flutter 프로젝트이며 현재 Windows 배포 진입점이 아니다.
- windows_print는 Windows 시스템 인쇄 연동 모듈이다.
- site/download는 플랫폼 감지, 다운로드, 언어 및 Mac 실행 안내 페이지다.
- localization/en.json이 번역 원본이다. scripts/generate_localizations.py로
  Dart/Python/Swift/사이트 번역을 생성한다. 생성 결과만 따로 수정하지 않는다.

확인한 소스 버전과 배포 경로
- Mac/웹 패키지: macos_app/pubspec.yaml 1.10.1+16.
- Windows: native_windows/version.py 1.7.0. installer/CYViewer.iss와 함께 갱신한다.
- 웹: https://kimmacaroni.github.io/CY_Viewer/
- 다운로드: https://kimmacaroni.github.io/CY_Viewer/download/
- 위 버전은 로컬 소스 기준이다. 이번 인수 작업에서 공개 설치 파일을 다시
  다운로드하거나 릴리스 및 SHA-256을 실시간 검증한 것은 아니다.

반드시 유지할 동작
- 한국어로 소통·문서·주석 작성. UI 수정 전 docs/CY_DESIGN_SYSTEM.md 확인.
- 문서 탐색 → 선택·편집 → 저장 흐름, 실제 파일명, 빈/선택/오류/완료 상태.
- macos_app/lib/cy_design.dart와 native_windows/design.py의 공통 토큰,
  좁은 화면의 문서 도구, 키보드 포커스와 터치 영역을 보존한다.
- 최근 목록 최대 5개. Mac 전체 문서 보관은 별도 유지, Windows 경로와
  즐겨찾기·페이지 메타데이터는 APPDATA/CYViewer, 웹은 원본 IndexedDB 사본.
- 파일 선택창이 열려 있는 동안 웹을 잠그지 않는다. 실제 읽기만 중복 차단.
  입력 컨트롤은 Flutter 밖 실제 DOM과 위치·클립·스크롤을 맞춘다.
- PDF 준비가 45초를 넘거나 실패하면 복구 안내와 브라우저 기본 뷰어 제공.
- 웹 인쇄 기본은 전체 페이지. 준비·취소·범위 변경의 늦은 응답을 무시한다.
  사용자 HTML 클릭 안에서 window.print(), 페이지별 PNG와 A4 인쇄 DOM 사용.
  기본 경로에서 외부 탭 자동 실행 금지. Safari 비동기 인쇄 자료는 대화상자를
  닫거나 범위를 바꿀 때 해제한다. 큰 문서에서 페이지를 조용히 누락하지 않는다.
- Drive 연결 전 업로드하지 않으며 연결 후 여는 원본부터 동기화한다.
  drive.file, 데스크톱 loopback/state/PKCE, 세션 메모리 토큰을 사용한다.
  PDF SHA-256 중복 제거·다운로드 검증, 페이지/책갈피별 시각 병합,
  ETag 충돌 최대 3회 재시도와 계정 세대 분리를 유지한다.
  편집 PDF 자동 업로드는 지원하지 않는다. 재저장한 파일을 다시 열면 새 해시다.
- Mac 업데이트는 1.10.1부터 공식 URL을 브라우저로 열고 마지막 Applications
  교체를 사용자가 수행한다. 과거 앱 내부 DMG 다운로드 설명을 현행으로 적용하지 않는다.
- Windows 업데이트는 크기·SHA-256 확인, 미저장 변경 확인, 종료 후 설치,
  성공 시 재실행이다. 개발 실행에서는 설치하지 않는다.

검증 및 배포 기준
- macos_app: flutter analyze, flutter test. 웹 릴리스 target lib/web_main.dart,
  base-href /CY_Viewer/. Mac/Windows 빌드와 실제 실행은 각각의 OS에서 확인.
- Windows 단위: python3 -m unittest discover -s native_windows/tests -p 'test_*.py'.
- 웹 저장/다운로드: npm ci --prefix tests, npm test --prefix tests.
- Mac 업데이트 소스 검증: python3 tests/check_mac_updater.py.
- .github/workflows/deploy-web.yml: PR 빌드 검증, main Pages 배포.
- build-macos.yml/build-windows.yml: 해당 버전 태그에서 설치 파일과 체크섬 게시.
- 앱 변경 배포는 버전 증가 필수. CI 성공, 게시된 실제 파일, SHA-256,
  실기기 GUI 확인은 서로 다른 근거로 보고한다.
- 이번 변경은 인수 문서만이며 앱 버전 증가·설치 파일 재배포 대상은 아니다.
