# 최근 열어본 파일

웹·Mac·Windows 모두 최근 목록은 최신순 최대 5개다. 다시 연 파일은 맨 위로 이동하며 중복하지 않는다. 이 기능은 각 기기·브라우저 안에서 동작하며 계정이나 서버를 통한 플랫폼 간 동기화를 하지 않는다.

- Mac: 문서함 기본 필터는 ‘최근 열어본 파일’이다. 기존 전체 문서와 즐겨찾기, 읽던 페이지·파일 접근 권한은 보존한다. 최근 표시에서 밀려나도 원본과 전체 문서함을 삭제하지 않는다.
- Windows: 시작 화면과 상단 ‘최근 열어본 파일’ 메뉴에서 다시 연다. 경로 목록을 APPDATA/CYViewer/recent-files.json에 보관한다. 이동·삭제된 파일은 기존 파일 열기 오류 안내를 표시한다. 저장하지 않은 변경이 있으면 다른 파일을 열기 전에 확인한다.
- 웹: PDF가 정상적으로 열린 후 원본 바이트의 사본을 IndexedDB에 저장한다. 내용 해시로 중복을 구분하고 최신 5개만 보관한다. 같은 이름의 다른 내용은 별개다. 새 파일 저장과 이전 사본 정리는 하나의 트랜잭션으로 처리하므로 저장 실패가 기존 목록을 지우지 않는다. 최근 행의 제거 버튼은 해당 로컬 사본도 지운다. 작업 중 주석 수정은 기존 PDF 저장·공유로 별도 보관해야 한다.
- 웹 저장소가 제한되거나 가득 차도 현재 PDF 열기는 계속 가능하며 저장 실패를 알린다. 브라우저 데이터 정리나 운영체제 저장 공간 회수로 사본이 사라질 수 있으므로 원본은 따로 보관한다. 사본은 서버에 업로드하지 않는다.

## 검증 방법

- `npm ci --prefix tests && npm test --prefix tests`: 실제 IndexedDB API를 모사하는 fake-indexeddb로 5개 제한, 중복 이동, 재조회·삭제, 바이트 무결성, 저장 실패 롤백을 검사한다. 실제 Safari 검증과 구분한다.
- `python3 -m unittest discover -s native_windows/tests`: Windows 경로 보관·복구·제한 및 기존 업데이트 검증.
- Flutter 테스트: Mac 최근 필터와 전체 문서·즐겨찾기 보존, 320/1024px 큰 글자·긴 파일명, 한국어·영어 동작과 기존 PDF 회귀 검사.

Mac 1.7.0 / Windows 1.4.0으로 배포한다. 실제 iPhone PWA에서 재실행 후 파일 열기는 별도 기기 확인 대상이다.
