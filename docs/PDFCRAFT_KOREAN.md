# 전체 PDF 작업실 한국어 번역

사용자는 일부 고급 메뉴까지 모든 기능을 한국어로 사용하도록 요청했다.
기존 기본 조작 번역을 원본 전체 카탈로그·실제 화면 문자열·명령/도구 목록·엔진 진단으로 확대했다.

- 기준 소스는 기존과 같은 PdfCraft 0.9.0 고정 커밋이다. 기능과 명령 ID를 교체하지 않는다.
- 메뉴, 도구 이름, 설정, 도움말, 빈/실패/완료 상태, 양식·서명·접근성·출력 검사와 보고서 문구를 번역한다.
- PDF 작업 용어를 교정하고 삭제 표시와 영구 삭제 적용, 주석과 양식, 가로·세로 인쇄를 구분했다.
- 23개 원본 언어 카탈로그의 모든 키와 실제 UI 리터럴, 전체 명령·도구 레이블, 엔진의 고정 진단을 대조한다.
  번역 누락, 중복, 빈 번역, 복수형, 줄임표, 숫자/이름 자리표시자 문제는 원본 카탈로그 파서와 검사에서 실패한다.
- 한국어가 기본으로 열리며 이전 작업실 설정에 영어가 남아 있어도 한국어로 시작한다.
- Mac 앱 메뉴를 한국어로 구성하면서 craft-quit의 미저장 문서 확인과 안전 종료 경로를 유지한다.
- 파일명·문서 내용·사용자 이름·명령 ID·PDF/인증서 기술 식별자·코드 예시는 번역하지 않는다.
  알 수 없는 OS·외부 공급자의 상세 진단은 한국어 안내와 함께 원문을 보존한다.
- 번역은 설치본에 포함된 정적 카탈로그다. 사용 중 온라인 번역 요청이나 PDF 업로드가 발생하지 않는다.
- UI 번역이며 원본 영어 OCR 모델, PDF 본문 글꼴/문자 지원, 예정·외부 서비스 기능의 구현 상태를 바꾸지 않는다.
- 원본 제작자·MIT·의존성·글꼴·OCR 모델의 고지는 유지한다.

검사: `python3 scripts/build_pdf_workbench.py --prepare` 다음
`python3 tests/check_pdf_workbench_korean.py`. 모든 플랫폼의 빌드에 포함한다.
실제 브라우저 검사에서는 한국어 도구 검색으로 주석·필드·본문 도구를 실행하고 한글 주석을 저장한 PDF를 독립 확인한다.

웹·Mac 1.17.1+28 / Windows 1.14.1 배포와 공개 파일 검증은 진행 중이다.
