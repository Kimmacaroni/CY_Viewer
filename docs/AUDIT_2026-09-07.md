# CY뷰어 기능 재점검 기록

## 확인한 항목

| 항목 | 결과 |
| --- | --- |
| 앱 이름·Windows 창 제목 | `CY뷰어`로 설정됨 |
| 앱 아이콘 | CY/PDF/문서 이미지 아이콘 적용됨 |
| PDF 열기 | PDF 형식만 선택하도록 구성됨 |
| 최근 문서·즐겨찾기·읽던 페이지 | 기기 로컬 저장소로 저장됨 |
| 검색·책갈피·페이지 이동·확대/축소 | 구현 및 코드 검사 완료 |
| 텍스트 선택 후 복사·표시 | 하단 도구막대 방식으로 재구성 |
| 우클릭 선택 메뉴 | 오류 원인이던 메뉴 경로를 사용하지 않도록 변경 |
| 코드 분석 | `No issues found` |
| 위젯 자동 테스트 | 통과 |

## 수정 내용

1. 텍스트 선택 후 나타나던 우클릭 메뉴를 제거했다. PDF 라이브러리 메뉴가 비어 있는 선택 좌표를 처리하지 못해 발생하던 `Null check operator used on a null value` 오류 경로를 없앴다.
2. 텍스트를 드래그하면 하단에 복사·형광펜·밑줄·취소선·강조 버튼이 나타나도록 바꿨다.
3. 표시를 모두 지우는 메뉴를 추가했다.
4. 남아 있던 Flutter 기본 예제 화면과 오래된 테스트를 제거하고 CY뷰어 기준 테스트로 교체했다.
5. 프로젝트 안내 문서를 실제 기능과 실행 방법에 맞게 갱신했다.

## 제한 사항

- 현재 형광펜·밑줄·취소선·강조는 앱 화면에서 보이는 표시다. PDF 파일 자체에 영구 주석으로 저장하거나 재실행 후 복원하는 기능은 아직 포함하지 않는다.
- 스캔본처럼 텍스트 레이어가 없는 PDF는 검색과 텍스트 선택이 제한된다.
- Android SDK가 현재 PC에 설치되어 있지 않아 Android 실행 파일은 검증하지 못했다. iOS/macOS 빌드는 각각 macOS와 Xcode가 필요하다.
