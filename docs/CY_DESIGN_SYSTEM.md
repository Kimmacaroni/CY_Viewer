# CY뷰어 디자인 시스템

이 문서는 CY뷰어의 모든 화면과 기능 작업에 사용하는 지속적인 기준이다.

## 제품 성격

CY뷰어는 개인용 PDF **읽기·표시·수정** 도구다. 화면은 장식보다 문서 작업의 집중, 안전한 편집, 명확한 저장 상태를 우선한다.

## 사용자 작업 흐름

```text
PDF 열기 → 읽기/검색 → 문구 드래그 선택 → 표시 또는 수정 → 다른 이름으로 저장
```

각 단계는 화면에서 다음 행동이 보이도록 해야 한다. 선택하지 않은 상태에서 편집 버튼을 누르면 이유와 선택 방법을 안내한다. 저장 전에는 원본을 바꾸지 않고, 저장은 새 파일을 기본값으로 한다.

## 화면 구조

| 영역 | 목적 | 포함 요소 |
| --- | --- | --- |
| 상단 바 | 현재 위치와 문서 정체성 | `CY뷰어`, 열린 파일명, 저장 상태 |
| 왼쪽 작업 패널 | 기능을 행동 단위로 묶음 | 문서 탐색, 텍스트 편집, 저장 |
| 문서 캔버스 | PDF에 집중 | 페이지, 검색 결과, 선택 영역, 주석 |
| 하단 상태 바 | 현재 결과를 짧게 전달 | 페이지, 확대 비율, 선택/저장 상태 |

## 컴포넌트 규칙

### 버튼

- 주요 행동은 한 화면에 하나만 강조한다. 예: `PDF 열기`, `PDF로 저장`.
- 보조 행동은 중립 버튼으로 표시한다.
- 파괴적이거나 원복하기 어려운 행동은 확인 절차와 설명을 둔다.
- 아이콘만 쓰지 않고, 처음 사용하는 기능은 한국어 라벨을 함께 쓴다.

### 텍스트 편집 도구

- 형광펜, 밑줄, 취소선, 굵게, 문구 수정은 반드시 `선택한 문구 편집` 그룹에 둔다.
- 문구를 선택했을 때 선택한 텍스트 일부와 다음 행동을 표시한다.
- `문구 수정`과 `굵게`처럼 PDF 본문을 바꿀 수 있는 동작은 저장 전 임시 편집 상태임을 알려야 한다.

### 피드백

- 파일 열기, 검색 결과 없음, 저장 완료, 저장 실패는 즉시 짧은 문장으로 알려준다.
- 오류는 무엇이 실패했는지와 사용자가 다음에 할 행동을 포함한다.
- 빈 화면에는 기능이 없는 회색 화면 대신 시작 행동을 안내하는 환영 화면을 표시한다.
