# CY뷰어 사용 설명서

## 설치와 실행

1. [최신 릴리스](https://github.com/Kimmacaroni/CY_Viewer/releases/latest)를 엽니다.
2. 최신 `CYViewer-Setup-*.exe`를 다운로드하고 실행합니다.
3. 설치 위치 화면에서 기본 경로를 사용하거나 `찾아보기`로 원하는 폴더를 지정합니다.
4. 추가 작업 화면에서 `바탕화면에 바로가기 만들기`를 선택하거나 해제합니다.
5. 설치가 끝나면 시작 메뉴 또는 선택한 바로가기로 CY뷰어를 실행합니다.

Windows에서 처음 실행할 때 보호 안내가 나타나면 파일을 GitHub의 공식 릴리스에서 받았는지 확인한 뒤 실행 여부를 결정하세요.

## PDF 열기

- 왼쪽 위 `PDF 열기` 버튼을 누릅니다.
- 또는 PDF 파일을 CY뷰어 창 안으로 끌어놓습니다.

## 문서 보기

- `이전`, `이동`, `다음`으로 원하는 페이지를 엽니다.
- `-`, `+` 또는 `Ctrl + 마우스 휠`로 화면을 확대·축소합니다.
- 보기 메뉴에서 한 페이지, 연속 스크롤, 좌우 보기를 선택할 수 있습니다.
- 책갈피 아이콘으로 현재 페이지를 저장하거나 다시 이동할 수 있습니다.

## 검색과 OCR

- 상단 검색창에 문구를 입력하면 문서에서 같은 내용을 찾습니다.
- 스캔 문서처럼 글자 선택이 되지 않는 PDF는 `OCR`을 실행합니다.
- OCR은 문서 전체의 한국어와 영어 글자를 인식합니다. 페이지가 많은 문서는 시간이 걸릴 수 있습니다.

## 선택, 표시, 수정

1. 문구를 마우스로 드래그합니다.
2. 선택 영역이 표시되고 선택한 내용이 화면에 안내됩니다.
3. 선택 영역을 마우스 오른쪽 버튼으로 누릅니다.
4. 형광펜, 밑줄, 취소선, 굵게, 문구 수정, 복사 중 필요한 기능을 선택합니다.

이미지와 글자가 없는 영역은 텍스트 편집 대상에서 제외됩니다.

## 저장

- `PDF로 저장`: 표시와 수정 사항을 포함한 PDF 사본을 저장합니다.
- `JPG로 저장`: 문서 페이지를 JPG 이미지로 저장합니다.
- `PNG로 저장`: 문서 페이지를 PNG 이미지로 저장합니다.

원본 보존을 위해 다른 이름으로 저장하는 것을 권장합니다.

## 인쇄

`인쇄`를 누르면 Windows 인쇄 설정 화면이 열립니다. 프린터, 방향, 매수, 페이지 범위를 확인하고 오른쪽 미리보기를 확인한 뒤 인쇄하세요.

## 문제가 있을 때

- 설치 파일 다운로드가 완전히 끝났는지 확인한 뒤 다시 실행합니다.
- 실행 중인 CY뷰어를 모두 종료한 뒤 다시 엽니다.
- PDF 파일이 다른 프로그램에서 잠겨 있지 않은지 확인합니다.
- 문제가 계속되면 [오류 제보](https://github.com/Kimmacaroni/CY_Viewer/issues)에 화면을 첨부해 주세요.
