# Apple HIG 기준 디자인 적용

웹·Mac 1.16.1+24, Windows 1.13.1에서 문서함·리더·PDF 도구의 표현과 조작을 다듬는다. 기능 엔진과 원본 보존·암호·병합·분할 정책은 기존 0.4.0을 유지한다.

## 근거와 기준

사용자가 Drive의 Apple-Design-AI-Reference.txt를 지정했다. 해당 자료의 원칙과 Apple 공식 Designing for macOS·Toolbars·Sidebars·Color·Typography·Sheets·Accessibility·Tab views 원문을 대조했다. 디자인 결정과 공식 링크는 CY_DESIGN_SYSTEM.md의 최신 Apple 항목에 기록했다. 비공개 Drive 파일 전체를 공개 저장소에 복제하지 않았다.

## 바뀐 화면과 사용 흐름

- 콘텐츠 표면에서 Material의 유색 tint를 걷어내고 시스템 의미별 색상의 밝음·어두움 변형으로 바꾼다. 보조 글자도 표면 대비 4.5:1 이상을 유지한다.
- Apple 환경에서는 Flutter의 Cupertino 시스템 글꼴 호출을 사용한다. 글꼴·심볼 파일을 재배포하지 않는다. Windows는 기존 시스템의 한국어 글꼴·파일 창·키보드를 유지한다.
- 툴바 밀도·반복 단계 번호·필터 선택 상태·컨트롤 모서리·여백을 정돈한다. Windows의 사용자 정의 주요 버튼도 hover·눌림·포커스 상태를 구분한다.
- PDF 도구는 경고 대화상자 외형 대신 큰 편집 작업 공간을 사용한다. 제목·실제 파일명, 편집 본문, 고정된 닫기·저장 영역을 분리한다. 좁은 화면에서는 전체 화면으로 표시한다.
- 다섯 작업 영역과 기존 PDF 기능을 유지한다. Apple 환경의 스위치·체크박스를 플랫폼에 맞춰 표시한다. 웹의 실제 HTML 입력·다운로드와 native 원본 보호 경로를 유지한다.
- 편집 창의 Cmd+S/Ctrl+S 저장, Windows Escape 닫기를 제공한다. 큰 글자·키보드 포커스·대비 강화 테마와 편집 영역의 동작 줄이기를 반영한다.

## 구현 범위와 한계

HIG는 플랫폼과 사용 맥락에 맞게 적용한다. Flutter·Tk 공통 UI를 AppKit/SwiftUI로 전면 교체한 것은 아니며 macOS 시스템 창·Liquid Glass·사용자 지정 macOS accent 색상과 동일하다고 주장하지 않는다. Apple 공식 인증이나 모든 HIG 항목의 완전 준수를 의미하지 않는다. 실제 사용자 기기의 VoiceOver·투명도 감소·OS별 모든 보조 기능은 별도 실기기 검사 범위다.

## 검증과 배포

문서함의 좁은 화면·큰 글자·긴 한국어/영어·빈 상태, 편집 도구의 기본 Mac 창과 저장·오류·완료 상태, 키보드 저장과 2배 글자·어두움·대비 강화, 본문/보조 글자 대비를 검사한다. 실제 브라우저에서 PDF·ZIP·암호 저장과 결과 재열기를 확인하고 OS별 빌드·설치·샌드박스 검사 및 공개 파일 체크섬을 구분해 기록한다. 최종 공개 검증은 작업 완료 후 덧붙인다.
