# 아이폰 듀오 웹앱 지원

기존 아이폰의 Safari·홈 화면 웹앱 접속 경로를 유지하면서, 외부·내부 화면 전환 및 회전으로 바뀌는 표시 영역에 전체 PDF 작업실을 맞춘다. 별도 모델명 감지나 고정 기기 해상도를 사용하지 않는다.

- 실제 visualViewport의 크기·오프셋으로 표시하며 키보드·브라우저 표시 영역 변화도 같은 경로로 처리한다. 미지원 환경은 창 크기를 사용한다.
- 문서와 편집 iframe을 유지하고 크기만 바꾼다. 다운로드 결과·미저장 변경도 보존한다.
- 안전 영역을 작업실 크기에 포함해 하단이 넘치지 않게 한다. 짧은 화면은 안내 여백을 줄이고 저장 행동은 줄바꿈한다. 최소 44px 터치와 기존 밝음·어두움·한국어를 유지한다.
- 닫으면 표시 영역 이벤트 구독과 예약 프레임을 해제한다. 원본 보존·미저장 확인·제작자 고지는 유지한다.
- 변경은 웹 호스트/CSS에 한정한다. Mac·Windows 설치본 버전 1.17.1/1.14.1과 편집 엔진은 바꾸지 않는다. 웹 캐시 식별자는 iphone-duo-20261023-1이다.

검증: Chrome·WebKit에서 표시 영역 API의 크기·오프셋 변경/미지원 대체/닫기를 검사했다. 실제 전체 작업실에서 주석·양식·본문 편집 후 466×678 → 890×626 → 626×890 → 466×360 → 1360×1000으로 바꾸고, 같은 iframe 유지·캔버스/닫기 표시 영역을 확인한 뒤 저장했다. 독립 PDF 검사에서 한글 주석·양식·본문·UTC 수정 시각이 모두 유지됐다. 기존 캐시·다운로드 검사 8개도 통과했다.

문서 도구의 선택 탭·제목 입력 유지와 일반/standalone 터치 경로도 Chrome·WebKit에서 통과했다. WebKit 어두운 모드에서 표시 영역 검사와 기존 어두운 표면색 유지도 확인했다.
