# CY뷰어 작업 로그

이 파일은 엄격한 append-only 감사 기록이다. 새 블록은 항상 파일 끝에 추가하며, 작성된 블록을 수정·삭제·재정렬하지 않는다. 정정·구현 완료·독립 QA·배포 결과도 원본 블록을 참조하는 별도 블록으로 추가한다. 실행하지 않은 검증은 `미실행`으로 표시하고, 구현 완료를 QA 통과나 배포 완료로 간주하지 않는다.

## 항목 템플릿

```markdown
## YYYY-MM-DD HH:MM UTC — 작업 제목

- 기록 종류: 작업 시작 | 구현 결과 | 정정 | 독립 QA | 배포
- 구현 상태: 미착수 | 진행 중 | 완료 | 중단
- 독립 QA 상태: QA 대기 | QA 통과 | QA 거부 | 대상 아님
- 배포 상태: 배포 미수행 | 진행 중 | 완료 | 대상 아님
- 담당 주체: 사용자/에이전트/작업자 식별자
- 요청자·검토자: 이름 또는 역할
- 브랜치 / worktree: `브랜치` / `$WORKTREE`
- 참조 기록: 원본 블록의 시각·제목·커밋 (최초 시작이면 `없음`)
- 기준 커밋: `SHA`
- 목표·범위:
- 대상 파일:
- 시작 확인: `git status` 결과와 기존 변경 유무
- 검증 계획:
- 수행 내용:
- 빌드·테스트 결과:
- 플랫폼 QA:
- 보안 확인: 비밀정보·고객 PDF·생성 산출물 미포함 여부
- 미검증·알려진 문제:
- 후속 작업·결정권자:
- 최종 커밋: `SHA` (커밋 전이면 `대기`)
- 배포 근거: 미수행 사유 | 대상 사용자/환경, 수행자, 저장소, 버전, URL, 체크섬
```
