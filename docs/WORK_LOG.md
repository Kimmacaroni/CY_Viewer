# CY뷰어 작업 로그

모든 항목은 최신 항목이 위에 오도록 작성한다. 작업 시작 시 먼저 항목을 만들고, 완료 또는 중단 시 같은 항목을 갱신한다. 실행하지 않은 검증은 `미실행`으로 표시한다.

## 항목 템플릿

```markdown
## YYYY-MM-DD HH:MM UTC — 작업 제목

- 상태: 진행 중 | 완료 | 중단
- 담당 주체: 사용자/에이전트/작업자 식별자
- 요청자·검토자: 이름 또는 역할
- 브랜치 / worktree: `브랜치` / `절대 경로`
- 기준 커밋: `SHA`
- 목표·범위:
- 대상 파일:
- 시작 확인: `git status` 결과와 기존 변경 유무
- 검증 계획:
- 수행 내용:
- 빌드·테스트 결과:
- 플랫폼 QA:
- 보안 확인: 비밀정보·고객 PDF·생성 산출물 미포함 여부
- 미검증·알려진 문제:
- 후속 작업·결정권자:
- 최종 커밋: `SHA` (커밋 전이면 `대기`)
- 배포: 미수행 | 대상 사용자/환경, 수행자, 저장소, 버전, URL, 체크섬
```
